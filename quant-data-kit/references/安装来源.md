# 环境与 Skills 安装来源

## 三个 Skill 的分工

老师参考版 `quant-data-kit` 调用已经验证的程序。学生先按开发指南写出自己的取数与清理方法，再编写自己的课程Skill。AKShare和Tushare的上游Skill可从开发开始就用于查询接口。

| 内容 | 来源 | 说明 |
| --- | --- | --- |
| 课程数据 Skill | 本套装 `SKILL.md` | 本地代码、清理规则和课程工作流 |
| AKShare 社区 Skill | [Z-AErIs/akshare-open](https://github.com/Z-AErIs/akshare-open) | 可核实的社区项目，不是 AKShare 官方发布的 Skill |
| Tushare Skill | [waditu-tushare/skills](https://github.com/waditu-tushare/skills/tree/master/tushare-data) | Tushare 官方仓库中的 `tushare-data` |
| AKShare Python 库 | [akfamily/akshare](https://github.com/akfamily/akshare) | 真正用于取数的库 |
| Tushare Python 库 | [waditu/tushare](https://github.com/waditu/tushare) | SDK 和本地凭证读取 |

教师机已有的 AKShare Skill 来自 SkillHub，安装记录未提供 GitHub 仓库地址。本套装保留现有安装；为其他电脑提供上表中的社区版作为可下载选项，不声称它与教师机现有版本完全相同。

## 推荐：下载成可导入 ZIP

在套装目录执行：

```bash
python scripts/download_skills.py --dest external-skills
```

程序下载两个公开仓库的指定版本，只提取 Skill 所需文档、脚本和资源，产生两个 ZIP。然后在 WorkBuddy 的 Skills 页面选择导入。上游来源和下载文件校验值写入 `SOURCE.json`。已存在的目录不覆盖。

本次固定版本：

- AKShare 社区 Skill：`4414efd78267bcb97642752d8e3c68c0d228a0c6`。
- Tushare Skill：`5e12b31d09123e262c5fb38564e80c26d05cb830`。

固定版本便于课堂复现。以后升级先检查接口，再统一更换班级使用的版本。

Tushare 官方也提供如下安装命令，但不同宿主如何发现安装目录仍需核对；WorkBuddy 首次使用更适合上面的 ZIP 导入方式。

```bash
npx skills add https://github.com/waditu-tushare/skills.git --skill tushare-data
```

这些步骤只准备 Skills。Python 依赖仍需要另外安装。

## Python 环境

建议 Python 3.11 或 3.12。环境脚本用运行它的解释器创建虚拟环境；先让 WorkBuddy 检查版本，再执行：

```bash
python3 scripts/setup_env.py --venv .venv
```

macOS 后续用 `.venv/bin/python`；Windows 用 `.venv\Scripts\python.exe`。PowerShell 调用带空格的路径时，在路径前加 `&`。

| 依赖 | 做什么 |
| --- | --- |
| AKShare | 免费行情、日历、中国宏观 |
| Tushare | 读取个人本地凭证，支持补充官方数据 |
| pandas、NumPy | 清理日期、字段和数值，计算变化量 |
| requests | 直接请求公开下载和 Tushare HTTPS 接口 |
| Beautiful Soup | 解析统计局公告网页 |
| tzdata | Windows 等环境中的中美时区支持 |

直接依赖版本写在 `requirements.txt`。AKShare 还会安装自己所需的 Excel、网页解析等依赖。**第一部分不需要 vn.py。**

教师机此次已单独建立环境，后续可以直接使用：

`/Users/ranli/github/multi-assets/量化教学/.venv-data/bin/python`

这个环境不在 ZIP 里；其他电脑应按脚本新建环境，不复制教师机环境文件夹。

## Tushare 凭证

代码按以下顺序寻找凭证：本地 `TUSHARE_TOKEN` 环境变量 → 用户私有配置 `.config/multi-assets/credentials.json` → Tushare SDK 已保存的个人配置。均没有时，`auto` 只使用免费来源。不同账号的接口权限可能不同，程序会记录具体接口错误。

新电脑可以在自己的终端用环境 Python 执行 `scripts/configure_credentials.py tushare`，粘贴输入自己的 token。不要把真实 token 填入配置示例或 Skill，也不用给 AI 发 token。

程序通过 [Tushare 官方 HTTP 接口](https://tushare.pro/document/1?doc_id=130) 以 HTTPS POST 发送请求，凭证只发给 Tushare 官方服务，不经过 MCP。缓存、日志和结果清单只保留接口名与参数，不保存认证字段。
