# 环境与数据源

本模块通过 Python 获取和处理数据，不依赖额外安装其他 Skill。需要查接口时，可参考以下上游项目：

| 组件 | 来源 | 用途 |
|---|---|---|
| AKShare | [akfamily/akshare](https://github.com/akfamily/akshare) | 免费市场与宏观接口 |
| Tushare | [waditu/tushare](https://github.com/waditu/tushare) | 使用个人权限补充行情及历史财务 |
| Tushare Skill（可选） | [waditu-tushare/skills](https://github.com/waditu-tushare/skills/tree/master/tushare-data) | 接口查询参考 |
| AKShare 社区 Skill（可选） | [Z-AErIs/akshare-open](https://github.com/Z-AErIs/akshare-open) | 社区接口说明，非 AKShare 官方 Skill |

## Python 环境

使用 Python 3.11 或 3.12。在用户研究目录建立虚拟环境，安装本模块 requirements.txt。也可使用 `python3.11 <数据kit目录>/scripts/setup_env.py --venv <研究目录>/.venv`。

macOS/Linux 使用 `.venv/bin/python`，Windows 使用 `.venv\Scripts\python.exe`；PowerShell 调用带空格的路径时在路径前加 `&`。运行环境与缓存放在插件目录之外。

基础依赖包括 AKShare、Tushare、pandas、NumPy、requests、Beautiful Soup 和 tzdata。美国证券及快照导入另装 requirements-extended.txt；数据整理和低频回测不需要 vn.py。统一插件可直接安装统一入口目录的 requirements.txt。

## 凭证

Tushare 按环境变量 `TUSHARE_TOKEN`、使用者主目录 `.config/multi-assets/credentials.json`、Tushare SDK 个人配置的顺序读取。没有凭证时，auto 使用可用免费来源。

在本地交互终端执行 `python <数据kit目录>/scripts/configure_credentials.py tushare` 配置凭证。代码通过 Tushare 官方 HTTPS 接口取数，不经过 Tushare MCP；缓存和结果不保存认证字段。

iFinD 使用同一配置命令的 `ifind` 参数，或环境变量 `IFIND_API_KEY`。它是可选补充服务，调用预算、缓存及原始响应处理见[iFinD可选数据源](iFinD可选数据源.md)。FRED 历史版本接口使用个人 `FRED_API_KEY`。
