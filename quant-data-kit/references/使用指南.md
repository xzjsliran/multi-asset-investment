# 获取投资研究数据

先确认研究起止日期、证券代码、宏观指标及输出目录。已有策略配置时沿用策略生成的数据计划，避免重复询问。境内 QDII 与直接海外证券分别选择对应的数据方法。

## 环境与凭证

使用 Python 3.11 或 3.12，在用户研究目录建立环境，安装本模块的 requirements.txt。安装方法及可选数据源见[安装来源](安装来源.md)。以下以 macOS/Linux 为例，执行前替换路径：

```bash
KIT='/你的数据kit目录'
WORK='/你的研究目录'
python3.11 "$KIT/scripts/setup_env.py" --venv "$WORK/.venv"
PY="$WORK/.venv/bin/python"
"$PY" "$KIT/scripts/run.py" doctor
"$PY" "$KIT/scripts/configure_credentials.py" status
```

Windows 的解释器位于 `.venv\Scripts\python.exe`。Tushare、iFinD 为可选项；需要新增凭证时，在自己的终端运行 `scripts/configure_credentials.py tushare` 或 `ifind`，通过不回显输入保存。

## 配置与获取

```bash
"$PY" "$KIT/scripts/run.py" init --out "$WORK/request.json"
```

修改 request.json 中的年份、资产及指标，再执行：

```bash
"$PY" "$KIT/scripts/run.py" fetch --config "$WORK/request.json" \
  --out "$WORK/data-01" --cache "$WORK/cache"
```

先读取 quality.json，检查每只资产覆盖、复权来源、缺失原因及宏观可用时点，再将 prices.csv、calendar.csv 等标准表交给策略模块。接口返回成功不等于所有历史输入均可用于回测。

改变年份或资产时另存配置；重跑使用新输出目录并复用缓存。需要更新缓存时加 `--refresh`。涉及美国证券、汇率或历史财务截面时，使用[扩展数据方法](海外行情与历史财务扩展.md)。
