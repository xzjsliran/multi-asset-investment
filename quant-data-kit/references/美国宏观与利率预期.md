# 美国宏观：下载、版本和加息预期

这一组数据用于观察美国通胀、就业和利率环境。它们与国内行情放在同一个数据包里，但保留自己的统计期和公布时间。

## 第一轮直接下载的指标

| 想看什么 | 配置名称 | 官方系列与含义 |
| --- | --- | --- |
| 美联储政策利率 | `fed_upper` | [DFEDTARU](https://fred.stlouisfed.org/series/DFEDTARU)：联邦基金目标区间上限 |
| 实际短期利率 | `fed_effective` | [DFF](https://fred.stlouisfed.org/series/DFF)：实际联邦基金利率 |
| 美国 CPI | `us_cpi` | [CPIAUCSL](https://fred.stlouisfed.org/series/CPIAUCSL)：月度季调 CPI 指数 |
| CPI 同比 | `us_cpi_yoy` | 同一季调序列相隔 12 个月的涨幅；与常见非季调新闻同比口径有区别 |
| 长期美债收益率 | `us_10y`、`us_30y` | [DGS10](https://fred.stlouisfed.org/series/DGS10)、[DGS30](https://fred.stlouisfed.org/series/DGS30)：10 年和 30 年恒定期限收益率 |
| 失业率 | `us_unemployment` | [UNRATE](https://fred.stlouisfed.org/series/UNRATE)：月度季调失业率 |
| 非农总就业 | `us_nonfarm` | [PAYEMS](https://fred.stlouisfed.org/series/PAYEMS)：季调非农就业人数，单位千人 |
| 新增非农就业 | `us_nonfarm_change` | 同一 PAYEMS 版本本月减上月，单位千人 |

FRED 的 CSV 下载可在本套装中直接调用，无需 API Key。同比计算会额外获取前 12 个月，新增就业会额外获取前一期，最后只保留用户需要的统计区间。月度缺项不会被跨月差分当作正常新增就业。

程序还接了 Cboe VIX。VIX 反映期权市场预期波动，美债收益率是债券市场价格形成的收益率，政策利率是已经实施的利率水平，三者分开保存。

## 月度数据为什么需要历史版本

今天下载的某年非农数据可能已经经历月度和年度修订。它可以用于研究历史经济变化，但不能直接证明“当时的交易者已经看到了这个数值”。CPI 季调和就业指标同样需要注意版本。

普通下载结果因此先标记为 `latest_revised`，不直接进入默认历史信号表。包里另有 FRED/ALFRED 历史快照方法：

```bash
python scripts/run.py fred-vintage --series PAYEMS --start 2024-01-01 --end 2025-01-31 --asof 2025-02-10 --out runs/payems_asof_20250210.csv
```

这个额外接口需要使用者自己的免费 FRED API Key，并在本地配置 `FRED_API_KEY`。普通 CSV 下载不受影响。官方申请与接口说明：[FRED API Key](https://fred.stlouisfed.org/docs/api/api_key.html)、[观测与历史版本参数](https://fred.stlouisfed.org/docs/api/fred/series_observations.html)。

`--asof` 的意思是“查询到那天为止可见的版本”。程序采用该日期的纽约次日零点作为快照可用时间，不把快照日期说成每条记录的最初公布日期。需要每月历史回测时，应按各决策日期分别取快照，再计算同比或新增值。当前第一版提供的是单次快照方法，尚未自动批量重建整段美国月度发布历史。

## 市场加息预期：用 CME FedWatch

市场对未来某次会议加息、维持或降息的概率，可以参考 [CME FedWatch](https://www.cmegroup.com/markets/interest-rates/cme-fedwatch-tool.html)。它利用联邦基金期货价格推算会议结果的概率。不要把 DFF、DFEDTARU 或 10 年美债收益率改个名字叫“加息概率”。

目前有两种获取方式：

1. **课堂先用网页下载。** 在 FedWatch 选择会议，查看 Historical / Downloads 区域。官方指南说明可下载该会议的历史概率 Excel；具体可选区间以当时界面为准。[官方使用指南](https://www.cmegroup.com/tools-information/quikstrike/cme-fedwatch-tool-user-guide.html)
2. **持续自动采集再考虑官方 API。** 2026 年 10 月 6 日核实，官方提供订阅制 FedWatch API，页面列出日终方案从每月 25 美元起。本套装没有购买服务，也没有接入需要订阅凭证的 API。[CME 官方 API](https://www.cmegroup.com/market-data/market-data-api/fedwatch-api.html)

第一版采用第一种方法。由 WorkBuddy 读取你下载的 Excel，按 `assets/fedwatch-columns.json` 整理字段；原始文件保留，概率不由 AI 猜。上游下载表的布局可能变化，因此导入程序读取明确的标准列，不假定所有 CME Excel 表头永远相同。

需要保留的字段包括：

- 观察时点：这个概率是哪天看到的。
- 会议日期：它预测哪一次会议。
- 每一档利率区间与概率：全部保留，概率换算到 0—1。
- 观察时点的当前政策利率：用于区分加息、维持、降息。
- 原始来源链接和时间处理说明。

只有观察日期、没有时间时，把它作为该日结束后的信息，从纽约次日零点使用，并在 `provenance_note` 中写明。不同日期下的当前利率要用当时值，不能统一填今天的利率。

整理好后运行：

```bash
python scripts/run.py expectations --input 工作目录/fedwatch_normalized.csv --out runs/fedwatch_first
```

程序检查概率范围、合计、重复档位、区间重叠、时区、当前利率一致性和会议先后关系，然后输出：

- `fedwatch_buckets.csv`：原有概率档位。
- `fedwatch_summary.csv`：加息概率、降息概率、维持概率、目标利率中点的概率加权值。

这部分与普通宏观表分开输出，因为一条预期还必须带着“针对哪次会议”。如果后续把它用于动态配置，再明确选最近一次会议还是某个固定期限，不能把不同会议的概率混成一条时间序列。

## 这一步有没有必要再写爬虫

利率、CPI、美债收益率和就业已有公开数据下载，不需要另写网页爬虫。统计局原公告需要补发布时间，本包已写轻量解析与目录抓取。FedWatch 先用官方导出，避免依赖易变化的网页内部请求。若以后确定需要自动获取历史加息概率，再接正式 API，比维护未经核实的隐藏接口更省事。
