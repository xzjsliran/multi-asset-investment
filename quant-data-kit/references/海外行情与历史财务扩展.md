# 为策略回测补充的数据

获取方法仍放在数据模块，策略模块按研究需求调用。模块中不附带真实下载数据。

先判断需要的海外敞口能否通过境内QDII实现。513100/513500直接走已有境内ETF通道，按人民币场内价格记账；用户选直接美国证券时才用下表的美国行情与汇率方法。选择说明见 [境内QDII与海外行情选择](境内QDII与海外行情选择.md)。

## 新增哪些输入

| 输入 | 来源和方法 | 用途 |
| --- | --- | --- |
| 美国上市ETF日线、复权价、分红记录 | Yahoo Finance，经yfinance | SHY、QQQ、SPY等海外持仓 |
| USD/CNY日线 | Yahoo Finance的CNY=X | 将美元资产收益换算人民币 |
| 历史估值和市值 | 本地Tushare daily_basic | 各信号日PE、PE_TTM、PB、股息率、市值 |
| 历史财务及公告日 | 本地Tushare fina_indicator / fina_indicator_vip | ROE、扣非利润、现金流、负债率 |
| 历史行业成员 | 本地Tushare index_member_all | 当时属于哪个行业、行业分散 |
| 上市退市信息及历史名称 | stock_basic、namechange | 上市年限、退市、当时的ST名称 |
| 已取得的FRED历史版本 | 现有fred-vintage方法，加fred-events转换 | 让美国月度指标接入按时间回测 |

股票历史筛选优先采用能提供公告日期和历史截面的Tushare；境内行情仍沿用AKShare优先、可选Tushare补充。美国ETF保留原始和复权字段，汇率单独处理。

接口说明：[Tushare每日指标](https://tushare.pro/document/2?doc_id=32)、[财务指标](https://tushare.pro/document/2?doc_id=79)、[历史行业](https://tushare.pro/document/2?doc_id=335)、[历史名称](https://tushare.pro/document/2?doc_id=100)、[yfinance历史行情方法](https://ranaroussi.github.io/yfinance/reference/api/yfinance.Ticker.history.html)。完整全市场年度财务接口需要相应账户权限，按当前官方文档是fina_indicator_vip；本地凭证直接用于官方HTTPS请求，不经过MCP。

## 安装

先安装基础 `requirements.txt`，再在同一个Python环境安装 `requirements-extended.txt`。扩展加入pyarrow和yfinance。

所有缓存写到用户指定的目录。API参数与获取时间可以保存，token不会写入配置或输出。正式下载按分页和有上限的子进程执行；网络失败可以复用已经成功的缓存。

## 历史选股截面

`scripts/extend.py stock-features --dates-file <JSON日期数组文件> --out <新目录> --cache <缓存目录>` 会生成 `stock_features.csv`。日期数组例如 `["2024-12-31", "2025-03-31"]`。

已有兼容研究快照时，可增加 `--research <研究快照目录>` 只读导入；没有快照时按所需日期联网获取输入。季度快照不能代替缺失的每周快照。

每个截面包含尚未筛选的历史股票，并保留财报公告日、报告期、行业有效期和名称。先筛掉信号日尚未公告的财报，再匹配最近年度及连续两年利润。供应商历史表可能经过修订，因此还保留版本说明。

财务字段单位：ROE和负债率为百分数，扣非利润为接口原始金额，市值为万元。选择逻辑放在策略模块，这里只生成输入表。

## 海外ETF和跨市场日期

`scripts/extend.py us-etf --codes SHY,QQQ,SPY --start 2024-01-01 --end 2025-12-31 --calendar <calendar.csv> --out <新目录> --cache <缓存目录>` 生成 `overseas_prices.csv`。策略模块的prepare会自动把它和境内行情合并。

纽约某日收盘通常在中国次日早晨才已知。程序以纽约当地16时作为美股日线可用时点，以汇率报价日期结束后作为汇率可用时点，分别向后对齐到中国交易日16时，再计算人民币价格。

输出保留 `us_quote_date`、`quote_available_at`、`fx_date`、`fx_available_at` 和 `usd_cny`。这个日期处理避免把尚未发生的美国收盘放到当天中国收盘之前。之后回测用这个已知报价成交，是低频回测的成交近似；不会把它称为同步可成交报价。

## 美国月度历史版本如何接入策略

普通FRED下载保存的是当前修订历史。若策略要参考当时的CPI或非农，可使用个人免费 `FRED_API_KEY`，调用原有 `scripts/run.py fred-vintage` 方法，取得各信号日之前的历史快照。

快照日期要留出时差：例如中国2025年3月31日16时决策，可取美国2025年3月30日及更早的快照。每个快照至少覆盖计算所需的历史期数，CPI同比要有13个月。

随后调用：

```text
scripts/extend.py fred-events --inputs <快照1.csv> <快照2.csv> --base <已有macro_observations.csv> --out <新目录>
```

这会转成统一的 `macro_observations.csv`；快照日纽约次日零点之后才允许使用。然后策略模块 `prepare --macro-data <这个新目录>` 可以读取它。转换器按每个历史快照内部的数据重新计算CPI同比、新增非农，避免混入后来修订的值。

历史版本请求需配置用户自己的 FRED_API_KEY。VIX和日频利率可通过原有免费接口获取，按声明的可用时点生成动态配置输入。
