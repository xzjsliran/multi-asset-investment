# 投资研究数据接入与整理

根据研究年份、资产和指标需求，通过本地代码获取市场、财务及宏观数据，统一证券代码、交易日、字段和信息可用时点。

给 Agent 的入口是 [SKILL.md](SKILL.md)，操作步骤见[使用指南](references/使用指南.md)。代码、配置示例和方法随包分发，实际行情、缓存、凭证和环境保存在使用者研究目录。

## 数据范围

- 境内 ETF（含 QDII）及 A 股日线、复权价格、成交信息与交易日历。
- 美国 ETF、USD/CNY、历史估值、财务、行业及证券名称截面。
- 中国 PMI、CPI；美国政策利率、CPI、长期国债收益率、失业率、非农；VIX 与全球年度增长。
- 统计局公告解析、FRED 历史版本及 CME FedWatch 下载表整理。
- 可选 iFinD 查询、原始响应、缓存及调用预算。

行情优先尝试免费来源，缺口可使用已配置的 Tushare 权限补充。每只证券按完整区间选择来源，不拼接不同来源的复权绝对价格。iFinD 响应需核对口径后再转换，尚不自动进入行情替换链。
