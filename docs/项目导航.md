## 本地文件怎样收纳

以下资料只在维护者本机保存，GitHub 源码快照中没有这些目录的内容。

| 本地目录 | 用途 |
|---|---|
| `资料/` | 本地内部归档，不进入源码或安装包 |
| `output/releases/v0.2.0/` | Codex、Claude Code、WorkBuddy 与 DSH 四个平台的安装包及说明 |
| `output/验证与测试/` | 各批次回测数据、报告、模拟调仓及验证证据；README 标出当前查看入口和早期批次 |
| `output/历史交付/` | 早期数据包和通用 Skill 文件夹，只供历史复核 |
| `references/` | Balanced Portfolio 参考源码及来源说明 |
| `.venv-data/` | 本机运行环境 |

每份资料保留一个维护位置。模块里的 `references/` 是投资研究与运行说明，随源码和插件分发；根目录 `references/` 是外部参考项目。

正式发行目录里的文件与 GitHub Release 对应。后续改动先修改源码，再生成新版本；试构建使用临时工作区。已发布的版本文件保持原样。
