# 多资产投资研究插件

将数据、策略、报告和调仓四个kit通过同一个Skill入口交给宿主Agent调用。支持固定比例、宏观条件配置、只做多风险平价，以及股票内部等权、指定比例或最小方差配权。

给Agent的入口是[SKILL.md](SKILL.md)；安装、启动和复现指令见[使用指南](references/使用指南.md)。完整交付文件夹包含四个kit；源码中的本目录通过上一级寻找各模块。

首次运行`python <插件目录>/scripts/run.py startup`检查本地环境，再由Agent确认研究年份、资产范围和策略要求。Tushare与iFinD均为可选；已有凭证复用，新增凭证通过本地终端不回显输入。启动检查不访问外部接口。

这个文件夹只分发方法、模板和配置样例，不包含真实行情、账户、结果、虚拟环境或密钥。iFinD先作为补充查询来源，每个工作目录默认最多4次数据调用，保留缓存和尝试次数。

操作步骤见[使用指南](references/使用指南.md)，报告采用专业投资研究模板。
