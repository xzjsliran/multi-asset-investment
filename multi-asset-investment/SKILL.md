# 多资产投资研究

计算由配套Python完成，当前宿主Agent负责理解需求、调用模块和解释结果。所有客户材料按投资研究口径撰写。

## 首次启动

1. 确定本Skill目录，执行`python <Skill目录>/scripts/run.py startup`。它只检查本地环境、模块与凭证状态，不联网、不返回密钥。
2. 向用户询问研究年份、资产范围、配权方式及调仓频率。可列股票、债券、黄金、其他商品、海外资产和现金；境内QDII与直接海外证券分别说明。
3. 询问是否有尚未配置的Tushare/iFinD密钥，或只使用免费来源。已有凭证复用，不重复索要。配置时让用户在本地终端运行`python <Skill目录>/scripts/run.py credentials tushare`或`credentials ifind`，通过不回显输入保存。密钥只在用户私有配置目录；不写入项目、普通命令参数、对话复述或报告。没有密钥照常推进可用的免费方案；某项数据必须授权时再说明缺口。
4. 数据、账户及输出都放在Skill目录外的用户工作目录。分发文件夹只含方法、模板和人工测试。

## 任务路由

按当前任务读取一个相关模块的SKILL.md。完整发行目录下四个kit与本入口并列；开发源码模式下位于入口的上一级。

| 需求 | 模块与命令 |
|---|---|
| 数据来源、年份、行情、宏观与历史财务 | `quant-data-kit/SKILL.md`；`run.py data ...`或`extend ...` |
| 配置、选股、回测 | `quant-strategy-kit/SKILL.md`；`run.py strategy ...` |
| 单策略/多策略比较、风险贡献、报告 | `quant-report-kit/SKILL.md`；`run.py report ...` |
| 现有账户后续调仓 | `quant-rebalance-kit/SKILL.md`；`run.py rebalance ...` |
| iFinD补充查询 | 数据kit的`references/iFinD可选数据源.md`；`run.py ifind ...` |

完整流程：确认需求→形成策略配置→检查数据需求→取数清理→回测→报告。用户请求实际调仓时，先确认当前策略与真实持仓、可卖数量、现金、时点，再复用策略决策生成计划；历史模拟账户仅用于历史情景测算。

## 配权与解释

- 大类配权可选固定比例、宏观条件配额、风险平价。第一版将宏观配额与风险平价作为独立方案比较；股票内部仍可选等权、指定比例、最小方差。
- 风险平价需事先选定各大类的风险代理ETF/篮子；向用户解释代理与实际持仓的区别，并保存代理代码、样本窗口和缺数处理。读取策略kit的`references/风险平价与风险贡献.md`。
- 全部资产只做多，现金不透支。负的风险贡献可能表示分散效果，不能误判为空头。
- 收益贡献、实际回测波动贡献、目标配置风险估计分别解释。多策略报告使用相同日期重新计算；不把目标风险均衡说成实际历史风险始终相等。
- iFinD默认作为可选查询与核对来源。先约定少量调用，使用同一工作目录累计预算和缓存；达到额度、权限错误或超时后不自动重试。原始响应需核对日期、单位、复权和版本后转换，不能将自然语言摘要直接充当回测表。
