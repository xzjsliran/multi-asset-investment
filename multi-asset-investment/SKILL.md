# 多资产投资研究

宿主理解需求、调用工具和解释结果。配套 Python 负责取数、计算、校验和报告。客户材料采用投资研究口径。

## 首次启动

1. 定位本 Skill 目录，用研究环境的 Python 执行 `scripts/run.py startup`。该检查离线运行，只返回依赖与凭证状态。
2. 沿用用户已提供的条件。数据、账户和报告保存在研究工作目录，插件目录只读。
3. 涉及特定来源时查阅[凭证与数据说明](references/使用指南.md)。可使用免费来源和已有凭证，凭证由使用者在本地配置。

## 历史研究

先读[研究任务操作](references/研究任务操作.md)，使用统一入口的 `research` 命令保存任务。缺失且会影响结果的条件才补问。例如“稳一点”需要落实为最大回撤、波动率或指定持有区间。条件齐全时直接执行。

- 先检查数据。已有标准行情和日历时直接用 `research preview`。遇到 `needs_input` 时按原因补同一证券、同一口径的数据，或请用户在具体区间选项中选择。改变证券、范围和研究问题时保留新任务。
- 预检允许继续时用 `research run`。读回 `execution_review` 和 `report_args`。全部回退时先解释原方法为何无法评价，再交付实际回退路径的历史结果。能补齐实质缺项时可复算。
- 客户报告的关键数字引用 `ai_context.json` 中的 `evidence_values`，由程序填入主体、数值、区间和单位。复核定性解释、比较条件和推断范围。
- “只把季度改成月度”沿用上次任务，使用 `research revise` 并检查 `change.strategy_fields`。数据满足新频率的覆盖时直接复用。

## 模块入口

按任务读取相应模块的说明。发行包的四个模块位于 Skill 目录内。源码中位于该目录的同级。

| 需求 | 模块与命令 |
|---|---|
| 行情、宏观和历史财务 | `quant-data-kit/SKILL.md`，调用 `data` 或 `extend` |
| 策略、准备数据和回测 | `quant-strategy-kit/SKILL.md`，调用 `strategy` |
| 对照、风险贡献和报告 | `quant-report-kit/SKILL.md`，调用 `report` |
| 当前持仓调仓 | `quant-rebalance-kit/SKILL.md`，调用 `rebalance` |

## 专业边界

- 全部资产只做多，现金不透支。当前持仓调仓先按调仓模块核对策略、持仓、可卖数量、现金及时间，并记录真实账户确认。
- 风险平价使用事先确定的代理资产和回看窗口。目标风险估计、实际历史风险贡献和收益贡献分别解释。
- 境内 QDII 与直接海外证券是不同标的。使用已有资产时优先检查原口径；更换证券需写入研究条件。
- iFinD 用于可选补充和核对。沿用调用预算与缓存，核实日期、单位、复权和版本后才使用。
