# 多资产投资研究

宿主理解需求、调用工具和解释结果。配套 Python 负责取数、计算、校验和报告。客户材料采用投资研究口径。

## 首次启动

1. 定位本 Skill 目录，用研究环境的 Python 执行 `scripts/run.py startup`。该检查离线运行，只返回依赖与凭证状态。
2. 沿用用户已提供的条件。数据、账户和报告保存在研究工作目录，插件目录只读。
3. 涉及特定来源时查阅[凭证与数据说明](references/使用指南.md)。可使用免费来源和已有凭证，凭证由使用者在本地配置。

## 确认交易费用

回测、续做出新结果或计算调仓计划前，先核对用户已说明的费用或已确认的同一研究配置。如果用户没提费用，主动问一次，按标的给出[交易成本说明](quant-strategy-kit/references/交易成本说明.md)中的切实选项。流动性较好的境内 ETF 可建议单边佣金和滑点各万分之 1.5，较高成本情景可建议单边合计万分之 10，也可明确选零成本对照。境内 ETF 与 A 股卖出印花税分别处理，跨历史税率先核对日期。实际账户优先用券商费率、交易品种及用户认可的滑点，同当前持仓确认合并提问。

版本源码中，交易成本说明位于同级的 `../quant-strategy-kit/references/交易成本说明.md`。

收到明确选择后，将费率保存到策略的 `transaction_costs`，或用同名字段修订已有研究。用户已给出确定口径时直接沿用。如果旧版配置仅有隐含的 `cost_rate: 0`，在重新计算前确认；只读旧报告时沿用其原始口径。换品种或费用假设发生变化时说明新增条件。

## 历史研究

先读[研究任务操作](references/研究任务操作.md)，使用统一入口的 `research` 命令保存任务。缺失且会影响结果的条件才补问。例如“稳一点”需要落实为最大回撤、波动率或指定持有区间。条件齐全时直接执行。

- 先检查数据。已有标准行情和日历时直接用 `research preview`。遇到 `needs_input` 时按原因补同一证券、同一口径的数据，或请用户在具体区间选项中选择。改变证券、范围和研究问题时保留新任务。
- 新研究保存任务后，用 `research track --task <任务目录> --data <数据目录>` 登记在研究工作目录，可重复 `--task` 登记已经确认的独立方案。用 `research continue` 预检、回测并生成报告。即使数据待补，也可先登记任务。需要自定义比较时，沿用 `research run` 与报告模块，生成后用 `research track --run <运行目录> --comparison <报告目录>` 登记，按需重复 `--run`。
- 全部回退时先解释原方法为何无法评价，再说明实际回退路径的历史结果。能补齐实质缺项时可复算。
- 客户报告的关键数字引用 `ai_context.json` 中的 `evidence_values`，由程序填入主体、数值、区间和单位。复核定性解释、比较条件和推断范围。

## 接续上一次研究

- 用户说“接着上次”“把上次那两个方案改成月度再比一次”时，在同一个研究工作目录先用 `research resume`。从本次返回的任务单、方案标签、条件和历史版本定位上次研究，旧会话无需加载。若工作目录不同，用 `--workspace` 显式指定原目录。
- 0.4 的旧研究可直接接入。只有一份可用的旧回测时，`research continue` 能接入。多份候选时从原比较报告确认组成并用 `research track` 登记；无法判断是哪项时，列出候选请用户选择。
- 用户只说“改成月度”且上下文在比较大类配置时，写入 `{"allocation_rebalance":"monthly"}` 并执行 `research continue --changes <变更文件>`。内部调仓只有在用户明确指定对应资产部分时才改。核对各方案的 `change.strategy_fields`、数据复用结果与实际报告。先交付报告，简述改动、实际对照和仍有影响的限制。
- `needs_input` 时读 `issue`，说明原数据被修改、缺少哪些文件或新设定缺少哪些日期。恢复同一数据后，可直接继续，已保存的修订仍然有效。用户明确指定了新的标准数据目录时，传 `--data`，说明本版数据口径有变化。

## 模块入口

按任务读取相应模块的说明。发行包的四个模块位于 Skill 目录内。源码中位于该目录的同级。

| 需求 | 模块与命令 |
|---|---|
| 行情、宏观和历史财务 | `quant-data-kit/SKILL.md`，调用 `data` 或 `extend` |
| 策略、准备数据和回测 | `quant-strategy-kit/SKILL.md`，调用 `strategy` |
| 对照、风险贡献和报告 | `quant-report-kit/SKILL.md`，调用 `report` |
| 当前持仓调仓 | `quant-rebalance-kit/SKILL.md`，调用 `rebalance` |

## 专业边界

- 全部资产只做多，现金不透支。当前持仓调仓先按调仓模块核对策略、持仓、可卖数量、现金及时间，并记录真实账户确认。
- 风险平价使用事先确定的代理资产和回看窗口。目标风险估计、实际历史风险贡献和收益贡献分别解释。
- 境内 QDII 与直接海外证券是不同标的。使用已有资产时优先检查原口径；更换证券需写入研究条件。
- iFinD 用于可选补充和核对。沿用调用预算与缓存，核实日期、单位、复权和版本后才使用。
