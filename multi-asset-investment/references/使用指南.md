# 多资产投资研究插件使用指南

交付文件夹内包含统一入口和四个kit，可整体移动，不需要网页服务或另外部署Agent。请保持目录结构。

## 安装与启动

在Python 3.11或3.12环境中，为该插件建立虚拟环境并安装根目录`requirements.txt`。研究直接海外证券时，再安装`quant-data-kit/requirements-extended.txt`。完整交付文件夹之外另建研究工作目录，保存数据、账户和结果。

在WorkBuddy或其他支持本地Skill、文件访问和终端的Agent里，把完整文件夹导入其Skill目录，或让Agent读取文件夹里的SKILL.md。具体宿主若没有Skill导入入口，可以先通过下方指令加载同一份说明。各宿主安装界面不同，本交付采用可移植的Skill文件夹，不依赖专有插件商店格式。

首次对话可直接说：

> 读取这个多资产投资研究插件的SKILL.md，先检查环境，再和我确认研究年份、资产范围、配权方法和调仓频率。检查我是否已有Tushare或iFinD凭证；尚未配置的询问我是否提供。我也可以先只使用免费数据源。数据和研究结果另存到我指定的工作目录。

入口命令：`python <插件目录>/scripts/run.py startup`。

## 凭证

Tushare和iFinD均为可选。首次启动只返回“已配置/未配置”，不会消耗查询额度。输入使用本地终端，不回显：

```text
python <插件目录>/scripts/run.py credentials tushare
python <插件目录>/scripts/run.py credentials ifind
```

默认保存于使用者主目录的`.config/multi-assets/credentials.json`，macOS/Linux限制为本人读写。也支持环境变量`TUSHARE_TOKEN`、`IFIND_API_KEY`；已有Tushare SDK本地凭证继续可用。环境变量优先于私有文件。

凭证不随文件夹分发；使用者配置自己的账号。没有凭证不影响AKShare等免费来源。iFinD返回的历史数据范围和导出容量取决于账号权益，先小量试取。

## 典型使用

> 比较2025年股票宽基、国债、黄金和商品ETF的固定比例与风险平价方案，按季度调仓。先让我确认代理资产、风险窗口和基础比例，然后回测，输出风险贡献及策略对比报告。

> 已有这些回测结果，请在共同日期重新比较收益、回撤和风险贡献，解释风险集中在哪些资产部分。

> 我想查看下次调仓计划。先核对当前策略、真实持仓、可卖数量和各币种现金，再计算目标和买卖差额。

可用`strategy init --preset risk-parity-demo --out <工作目录>/strategy.json`生成参数样例，然后用`strategy plan`确认所需数据。完整命令参数分别见四个kit的指南；统一入口只是将命令转交给对应模块。
