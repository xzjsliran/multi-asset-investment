# 投资回测报告生成指南

本指南供项目使用者调用现有功能；学生从理解需求到自行开发的流程另见专门开发指南。

回测报告检查只做多配置及已提供的持仓记录。调仓计划使用独立入口：`scripts/run.py rebalance --plan <调仓结果目录> --out <新报告目录>`，输入由相邻`quant-rebalance-kit`生成。该报告分别展示当前、目标和预计调整后持仓，并核对交易数量与各币种现金的变化。

## 准备

让WorkBuddy或其他能够读取文件、运行Python的agent读取本模块SKILL.md。复用数据和策略模块的Python环境；独立部署时运行：

```bash
python3 -m venv .venv-report
.venv-report/bin/python -m pip install -r quant-report-kit/requirements.txt
```

Windows解释器通常位于`.venv-report\Scripts\python.exe`。下列命令使用本项目已有环境，宿主按实际位置替换。

## 用自然语言调用

> 读取quant-report-kit/SKILL.md，按投资回测报告2.1模板比较我指定的回测结果。报告面向商业客户，标题用“资产配置策略对比”。请根据实际配置设置专业策略名称，统一比较区间、币种和绩效口径，分析收益风险、配置差异及收益贡献，保留实际回测假设。先生成事实材料，再撰写有依据的研究解读，核对内容及报告文件，输出到新的报告目录。

现有专业版报告见`output/投资回测报告_20261007/报告索引.md`。页面的“策略选择”切换该策略明细，“对照组合”切换绩效及配置差异。

## 单策略及配套对照

```bash
.venv-data/bin/python quant-report-kit/scripts/run.py single \
  --result "output/策略数据交接_20261007/VIX动态配置_2025" \
  --name "VIX动态资产配置策略" --title "动态配置策略回测分析" \
  --out "output/动态配置研究报告"
```

默认包含实际导出的主策略、组合内等权对照、固定权重对照和市场基准。`--main-only`只看主策略；`--start/--end`收窄日期。可用`--metadata <JSON>`提供实际机构、署名和报告版本等信息。

## 比较不同策略或不同版本

保存配置文件，路径相对该文件解析：

```json
{
  "schema_version": 1,
  "title": "资产配置策略对比",
  "alignment": "common",
  "report": {"version": "2.1"},
  "strategies": [
    {"id":"base", "label":"基础配置策略", "result_dir":"results/base", "scenario":"strategy"},
    {"id":"dynamic", "label":"条件动态配置策略", "result_dir":"results/dynamic", "scenario":"strategy", "display":{"sleeves":{"stocks":"A股动量组合"}}}
  ]
}
```

```bash
.venv-data/bin/python quant-report-kit/scripts/run.py build \
  --config "研究目录/compare.json" --out "研究目录/数据报告"
```

继续增加策略时在strategies中添加对象。选择某份结果的固定权重对照使用`scenario=static`，等权为`equal_weight`，市场基准为`benchmark`。`inspect --result <目录>`列出可用场景。

## 撰写研究解读

> 读取刚生成的ai_context.json和报告规范。根据本次事实撰写研究摘要和必要的比较分析，核对每个数字、对象和推断；不要重复逐项报数，不从横向差异推出单项规则的因果效果。将解读保存为符合commentary.schema.json的JSON，再用原配置生成带解读的报告新版本。

```json
{
  "sections": [
    {
      "section":"summary",
      "title":"配置规则与风险收益特征",
      "text":"填写基于本次结果核对后的研究结论。",
      "evidence_ids":["F001", "F002"]
    }
  ]
}
```

`section`取summary、comparison或portfolio；前者替换默认研究摘要。其他两类放到比较或贡献章节。事实编号必须来自本次报告。上述文字是字段说明，不是可交付正文。

```bash
.venv-data/bin/python quant-report-kit/scripts/run.py build \
  --config "研究目录/数据报告/report_config.json" \
  --commentary "研究目录/研究解读.json" --out "研究目录/正式排版版本"
.venv-data/bin/python quant-report-kit/scripts/run.py check \
  --report-dir "研究目录/正式排版版本"
```

程序核验事实编号和有限内容规则；agent另行核对正文是否得到引用事实支持。机构发布信息由实际出具方提供。

## 接入外部净值

准备date/nav表，先核实入金出金处理、币种及估值日历。运行：

```bash
.venv-data/bin/python quant-report-kit/scripts/run.py import-nav \
  --csv "研究目录/策略净值.csv" --name "外部配置策略" --currency CNY \
  --out "研究目录/adapted/strategy"
```

将新目录加入比较配置。该轻量入口不导入持仓和决策明细；相应分析只在提供证据后进行。

## 交付与复核文件

| 文件 | 用途 |
|---|---|
| 报告.html | 客户报告、图表和交互查询 |
| 报告解读.md | 相同结构的文字及数据表 |
| comparison.csv、curves.csv、monthly.csv、annual.csv | 共同区间指标与收益序列 |
| contributions.csv、rule_differences.csv | 贡献和配置字段差异 |
| report_data.json、ai_context.json | 完整研究数据与agent事实材料 |
| report_config.json | 复现本次报告的配置，含原路径 |
| checks.json、publication_checks.json | 计算检查、内容检查及未提供的机构信息 |
| manifest.json | 输入和输出文件指纹 |

客户阅读HTML或文字报告；内部路径及机器复核文件按需要随附。不要直接修改HTML中的数字，应修正输入后重新生成并核验。
