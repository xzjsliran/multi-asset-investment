# 维护与验证

## 代码分工

- `scripts/reportkit/inputs.py`：读取、日期/净值核对、场景选择。
- `scripts/reportkit/analysis.py`：共同区间、指标、贡献、记录截取、规则差异与事实。
- `scripts/reportkit/reporting.py`：专业名称、报告结构、披露、对照识别及内容检查。
- `scripts/reportkit/exports.py`：表格、AI材料、文字报告、HTML数据注入。
- `assets/ReportContent.jsx`、`assets/report.css`：报告页面内容。
- `assets/report-template.html`：已编译的空数据离线模板。
- `scripts/run.py`：日常入口；`scripts/build_template.py`：页面维护时重建模板。

## 运行检查

在项目根目录：

```bash
.venv-data/bin/python -m unittest discover -s quant-report-kit/tests -v
```

测试使用人工数字验证共同区间重算、最大回撤/恢复、贡献加总、币种和日期不一致、内置对照隔离、外部净值导入、输入保留、事实引用和HTML数据转义。真实案例另外核对报告数值与原回测summary、comparison、每日盈亏。

策略计算尚未变动时，不必重取市场数据来检查页面改动。生成一次真实案例后，在浏览器检查曲线确实绘出、策略切换后持仓对应、规则组合切换正确，并查看窄屏表格是否能在内部滚动。

## 页面模板怎样维护

普通使用无需重建页面模板。调整布局时先修改JSX/CSS，再用本机安装的 Data 报告组件构建。以下路径是当前维护环境示例，应按维护环境替换：

```bash
.venv-data/bin/python quant-report-kit/scripts/build_template.py \
  --node /Users/ranli/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node \
  --data-plugin /Users/ranli/.codex/plugins/cache/openai-curated-remote/data-analytics/1.0.11 \
  --workdir /Users/ranli/Documents/Codex/temp/quant-report-template-new
```

这个过程只编译报告的共享图表/交互组件和本模块页面，不需要网络安装前端依赖。构建目录应为新目录。输出模板只有数据占位符，Python生成报告时注入本次结果；共享运行时保留原样，不写入作者会话编号。`assets/template-info.json` 记录模板和源文件指纹。

JSX通过 Data app 的公开组件接口工作，源码维护环境需要该组件库；已经编译好的报告模板和生成后的HTML可独立离线使用。模板升级后重复计算测试与浏览器检查即可。

## 后续扩展

可继续接入组合回撤阶段分析、更多基准、资产层贡献或批量参数实验。新增内容先加入统一分析JSON，再由页面和文字共用。最新目标与调仓计划另开模块，报告模块读取其结果后可以再增添展示。

报告模板及调用Schema随代码维护。当前结构2.1版保持输入交接schema_version=1；HTML、Markdown和AI上下文共享章节和显示名称。禁止把内容格式检查标为法律合规认证。
