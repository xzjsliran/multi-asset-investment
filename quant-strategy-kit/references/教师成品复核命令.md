## 联网重取和安装

有历史财务权限时，prepare不传research即可联网取数，默认auto先试免费行情，历史财务用本地Tushare。需要复用之前缓存时加 `--cache <目录>`。纯免费参考用classroom-demo及 `--provider free`，取数失败会列出缺项。

首次环境安装：

```bash
.venv-data/bin/python -m pip install -r quant-data-kit/requirements.txt -r quant-data-kit/requirements-extended.txt -r quant-strategy-kit/requirements.txt
```

新电脑先用数据模块setup_env创建独立环境，后续命令替换为该环境的Python。Windows路径与教师机不同，不复制教师机虚拟环境。

## 读结果

先看checks.json、optimization.json、regimes.json及缺口表，再将整个结果目录交给报告组。summary.json和comparison.json已有指标，curves.csv已有日期对齐后的净值。详细口径见 [交接说明](交给报告组的数据说明.md)。

宏观参考用已有第一部分数据时，可直接指定其目录执行backtest；用research准备动态配置时，还要传 `--macro-data <宏观数据目录>`。改变股票调仓频率会增加历史截面需求，季度原始快照不能直接变成每周截面。
