# 配置策略与运行回测

先明确资产范围、历史区间、初始资金、各部分配权、选股规则及调仓频率。参数说明见[配置与计算说明](配置与计算说明.md)，默认跨境配置见[跨境资产配置说明](跨境资产配置说明.md)。

## 运行环境

复用统一插件的 Python 3.11 或 3.12 环境。独立使用时，在研究目录建立虚拟环境，安装本模块及相邻数据模块的 requirements.txt；美国证券与历史快照功能按需增加数据模块 requirements-extended.txt。

以下示例中，ROOT 是包含四个 kit 的目录，WORK 是用户研究目录：

```bash
ROOT='/你的插件Skill目录'
WORK='/你的研究目录'
PY="$WORK/.venv/bin/python"
"$PY" "$ROOT/quant-strategy-kit/scripts/run.py" init \
  --preset risk-parity-allocation --out "$WORK/strategy.json"
```

按用户要求修改 strategy.json。固定比例、宏观条件及风险平价分别设定；所有权重非负、总投资比例不超过100%，未投资部分留现金。

## 准备数据与回测

```bash
"$PY" "$ROOT/quant-strategy-kit/scripts/run.py" plan \
  --config "$WORK/strategy.json" --out "$WORK/data-plan.json"
"$PY" "$ROOT/quant-strategy-kit/scripts/run.py" prepare \
  --config "$WORK/strategy.json" --data-kit "$ROOT/quant-data-kit" \
  --work "$WORK/prepared-01" --cache "$WORK/cache"
```

读取 prepare 返回的数据目录及检查记录，再把该目录作为 backtest 的 data 参数：

```bash
"$PY" "$ROOT/quant-strategy-kit/scripts/run.py" backtest \
  --config "$WORK/strategy.json" --data "$WORK/prepared-01/data" \
  --out "$WORK/results/strategy-01"
```

已有标准数据可以跳过 prepare。读取 handoff.json、checks.json、optimization.json 和 regimes.json，核对配置、缺数处理及求解状态；输出字段见[回测结果与报告接口](回测结果与报告接口.md)。将结果交给报告模块生成分析与比较。

用户改变资产或历史区间时保存新配置；仅改变等权与最小方差时，可复用相同输入开展对照。股票调仓频率变化会改变所需历史财务截面，需重新检查数据需求。
