# 交易成本说明

新建回测、按旧研究另算一版或生成调仓计划前，先核对是否已有本次可沿用的费用口径。没有确认时，向用户给出与其资产范围对应的选项。用户确认后把费率写入策略的 `transaction_costs`。已确认的费率可以随同一研究版本复用。旧版预设中隐含的 `cost_rate: 0` 仅表明旧结果的口径，新计算要重新确认。

## 可供确认的费率

| 用途 | 单边佣金 | 单边滑点 | 印花税 |
|---|---:|---:|---|
| 流动性较好的境内 ETF 模拟 | 0.015% | 0.015% | 0 |
| 较高成本敏感性情景 | 0.030% | 0.070% | 按涉及的品种和历史时期填写 |
| 零成本对照 | 0 | 0 | 0 |
| 实际账户调仓估算 | 按券商费率或交割单核对 | 按实际点差、交易量估算 | 按品种及执行日期核对 |

参考情景沿用 balanced portfolio 的佣金及滑点数量级，是模拟假设。佣金和滑点各按万分之 1.5 时，合计单边万分之 3。较高成本情景合计单边万分之 10，可用于观察换手对结论的影响。若海外 ETF 采用不同费率，分别填写佣金和滑点。报价估算只计本节列出的比例成本，最低佣金、单独收取的过户费、外汇兑换费、管理费和其他固定费用由使用者另外核算。

境内 ETF 二级市场交易免证券交易印花税。A 股只在卖出时计税，2023 年 8 月 28 日起由 0.10% 降为 0.05%。跨过费率变更的历史回测按成交日配置，研究覆盖更早区间时先核对更早的历史费率。 [上交所 ETF 费用说明](https://etf.sse.com.cn/fund/learning/knowledge/c/5704298.shtml) · [财政部、税务总局减半征收公告](https://tianjin.chinatax.gov.cn/11200000000/0300/030004/03000418/20230828081811621.shtml) · [上交所 A 股交易费用](https://one.sse.com.cn/onething/gptz/)

## 写入策略配置

费率采用小数。以下示例用于包含境内 ETF 和 A 股、从 2020 年开始的模拟，海外 ETF 如入选则使用单独费率。

```json
{
  "transaction_costs": {
    "commission_rate": 0.00015,
    "slippage_rate": 0.00015,
    "stamp_duty_rate": 0.001,
    "stamp_duty_schedule": [{"from": "2023-08-28", "rate": 0.0005}],
    "by_kind": {"us_etf": {"commission_rate": 0.0002, "slippage_rate": 0.0003}}
  }
}
```

- `commission_rate` 和 `slippage_rate` 以实际模拟成交额为基数，买入和卖出各自计提。买入所需现金含费用，卖出回款扣除费用。
- `stamp_duty_rate` 只作用于 `stock`。`stamp_duty_schedule` 按成交日切换税率，变更生效前使用 `stamp_duty_rate`。单一近期 A 股区间可填写已核对的固定税率。
- `by_kind` 允许按 `stock`、`etf`、`us_etf` 覆盖佣金和滑点。用户说“总成本万三”时，可把万分之三作为经确认的单边综合费率记录，避免把同一笔费用再算一遍。实际账户需要明确税费是否已包含。
- 明确只用零成本时，策略写入 `"transaction_costs":{"commission_rate":0,"slippage_rate":0,"stamp_duty_rate":0}`。只有用户已确认并选择的费率才写入，预设可用于取数和预检。
- 回测用人民币核算，建仓及之后的实际模拟成交扣费。报告自建仓日起算时计入首日费用，子区间以共同首日收盘净值为基准。市场基准列示费前价格收益。
- 调仓按最终拟交易净额用交易原币估计，并按已知汇率折算人民币。假设成交后，账户权益加费用等于估算前权益。策略外的历史持仓若无法识别品种，在相应报价补 `kind`。
