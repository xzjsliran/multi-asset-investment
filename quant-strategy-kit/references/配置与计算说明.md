# 配置和计算说明

完整可执行示例在 `assets/`。先复制某个示例，再让智能体按用户要求修改。权重用小数：0.12表示12%；ROE、PE及宏观阈值沿用指标原单位，例如ROE门槛8表示8%。

所有资产只做多：`position_policy=long_only`，不允许空头或融资杠杆。大类、动态和证券配权必须有限且非负；大类权重合计不超过100%，剩余留现金。卖出金额可以为负，含义是减少已有持仓。回测与调仓共用`strategykit.decision.decide`。

## 组合分为若干资产部分

每个 `sleeves` 项有独立的 `id`、`weight`、`assets`、`selection`、`weighting` 和 `rebalance`。总权重不得超过1，剩余为零收益现金。

- `allocation_rebalance`：整个组合调整大类预算的频率。
- 每个部分的 `rebalance`：该部分重新选资产、计算内部比例的频率。
- 内置预设的大类预算及各部分默认使用 `monthly`。用户可在 `allocation_rebalance` 和各部分的 `rebalance` 分别指定 `weekly` 或 `quarterly`。地区宏观及波指随大类事件更新。
- 大类调整但某部分未到选股日时，按该部分现有内部比例缩放资金，不额外选股。
- 只有股票部分到调仓日时，使用股票部分当时的资金，其他部分持仓不变。

`assets` 中写明 `code`、`kind`、`name`。类型包括 `etf`、`stock`、`us_etf`、`qdii_nav` 和 `usd_deposit`。场外基金需指定 `redemption_days`。可用 `from`（含）和 `until`（不含）规定替代资产的有效区间。

## 资产选择方式

| selection.method | 做什么 | 常用参数 |
| --- | --- | --- |
| fixed | 持有用户明确列出的资产 | assets中的有效区间 |
| momentum | 候选池中按历史涨幅排序 | lookback、top_n、min_return |
| quality_value | 行业龙头、质量和估值规则 | min_roe、max_pe_ttm、max_pe、leaders_per_industry、max_per_industry |
| fundamental | 用户自己写的简单基本面条件 | filters、rank_by、top_n、max_per_industry |
| quality_value_dividend | 默认中证 800 的价值、质量现金流、红利低波及小市值 | universe、top_n、buffer_rank、max_per_industry、small_cap_weight |

### 主动 A 股多因子

用 `init --preset csi800-factor-monthly` 生成月度研究配置。以沪深300全收益（`H00300.CSI`）比较主动 A 股仓。`prepare` 使用已有本机 Tushare 权限，分区下载并保存快照，可用 `--cache` 接续。读取原始快照需安装数据模块扩展依赖中的 PyArrow。基准指数缺开盘点位时，使用前一交易日收盘点位，并记录起算日期。

在主动股票仓的 `selection.universe` 中指定候选池。

| 值 | 股票池 |
|---|---|
| `csi800` | 中证 800，默认 |
| `all_a` | 历史全 A，北交所自开市起计挂牌年限 |
| `sse50`、`csi300`、`csi500`、`csi1000` | 上证 50、沪深 300、中证 500、中证 1000 |
| `star_market`、`star50` | 科创板、科创 50 |
| `["600519.SH", "000001.SZ"]` | 自选代码候选池，仍执行多因子过滤与配权 |

指数池用信号当日或此前最近的完整成分快照，记录实际快照日期。扩大候选范围会重算分位数和行业标准分。

组合与各部分默认按月调仓。整套切到季度时，把 `allocation_rebalance` 和各部分的 `rebalance` 设为 `quarterly`。

- 在每个信号日验证所选历史股票池。上市满 365 天，剔除当期 ST、退市警示、缺报价、过去 20 日日均成交额低于 3000 万元的标的。用后复权日线计算120日波动率及20日涨幅。
- PE和PB须为正，行业内 PE 最高30%、全基础池120日波动率最高20%及20日涨幅最高10%均剔除。经营现金流TTM与正净利润TTM之比至少0.8。若商誉字段有披露值，商誉超过归母权益20%时剔除。
- 财务用实际披露日，截至信号日匹配最近的合并报表。季报累计流量按本期累计加上年全年减上年同期计算TTM。ROE用过去一年归母利润除以同季两期的平均归母权益。自由现金流减去实际资本支出，资本支出缺值的记录退出评分。股息率用过去12个月已实施现金分红总额除以当日总市值。
- 因子先截断至中位数±3MAD，再用行业Z分数，少于5只的行业用全体通过过滤的股票计算Z分数。小市值采用信号日总市值的负对数并使用相同标准化。内置配置的价值、质量与现金流、红利低波各占 30%，小市值占 10%。`small_cap_weight` 表示小市值评分权重，范围为 0 至 0.70。红利低波固定占 30%，价值与质量现金流各分其余权重的一半。旧配置省略该字段时使用原来的 35%、35%、30%。
- 取 20 只，一级行业最多 2 只。默认先保留仍通过过滤且排在前 40 名的持仓，再补足。用 `buffer_rank: 0` 可关闭缓冲。入选名单按 120 日波动率倒数配权，单股上限 8%。可用个股过少时保留现金。
- `execution_price=open` 以次期首个交易日开盘价执行差额，按收盘价估值。开盘停牌的股票不进入当日目标，已有受限持仓留到可成交时处理。开盘触及不利涨跌停的一侧暂缓。买入费率0.05%、卖出费率0.15%为本对照的固定情景参数。

自定义规则例子：只筛PE_TTM和年度ROE，然后按PE从低到高取五只：

```json
{
  "method": "fundamental",
  "universe": "all_a",
  "top_n": 5,
  "min_listing_days": 365,
  "exclude_st": true,
  "max_per_industry": 0,
  "filters": [
    {"field": "pe_ttm", "op": ">", "threshold": 0},
    {"field": "pe_ttm", "op": "<", "threshold": 30},
    {"field": "annual_roe", "op": ">", "threshold": 10}
  ],
  "rank_by": [{"field": "pe_ttm", "ascending": true}],
  "fill_shortfall": "cash"
}
```

可用字段：`pe`、`pe_ttm`、`pb`、`dv_ttm`、`total_mv`、`annual_roe`、`annual_ocfps`、`debt_to_assets`、`profit_dedt`、`roe_yearly`。筛选条件之间为“并且”，比较符为 `>`、`>=`、`<`、`<=`、`==`。排序可列多个字段；最后以代码打破并列，保证重跑一致。

`universe` 可填 `all_a` 或明确代码数组。默认上市满一年、排除当时ST；可自行改动。`max_per_industry=0` 表示不限制行业只数。财务字段仍需已公告，估值按历史截面；价格选股不会自动继承原示例的财务门槛。

计划选五只只选出三只时，默认只投资该部分的3/5，缺额留现金。设置 `fill_shortfall=redistribute` 可在入选股票间分完这部分资金。

## 股票如何配权

`weighting.method` 支持 `equal`、`fixed`、`min_variance` 及多因子策略使用的 `inverse_volatility`。固定配权在各个asset中加 `weight`，程序将其归一到该部分内部100%。

最小方差解的是：

\[
\min_w w^\top\Sigma w,\qquad \sum_iw_i=1,\quad 0\leq w_i\leq u.
\]

Σ取信号日前选中股票的历史收益协方差。默认126个交易日，至少60期所有入选股都有收益的共同样本；不跨缺失价格计算单日收益。

默认用 `0.9 × 样本协方差 + 0.1 × 样本方差对角矩阵`，即 `shrinkage=0.1`。设0就是直接使用样本协方差。`max_weight=0.4` 表示每只最多占该部分40%，不是整个组合40%。

数据不足或求解失败时，本期回退等权并记录原因。入选股票太少、无法在单股上限内分满资金时，各股仍遵守上限，多余资金留现金，例如两只股票、每只上限40%时最多投入该部分80%。

最小方差可能给某只股票0权重；“入选五只”不保证五只都有正持仓。目标是降低估计方差，实际回测未必收益更高或回撤更小。

## 宏观动态配置

`regional-macro-allocation` 对应 [中美四状态示例](../assets/macro-cycle.example.json)。启用 `macro.enabled` 后，各地区读取自己的 `rules`，选择第一条成立的状态，并应用符合条件的 `modifiers`。中国用制造业 PMI 和 CPI 同比变化分四种状态，操作利率和全国城镇调查失业率提供附加条件。美国用失业率三月变化和 CPI 同比变化分状态，美联储利率变化提供附加条件。状态中的调权幅度是可以修改的研究假设。

```json
{"series": "cn_pmi", "op": ">=", "threshold": 50, "max_age_days": 62}
```

`transform=level` 比较当前水平，`change` 比较最近值与前 N 期之差，`mean` 比较最近 N 期均值。N 由 `periods` 指定。变化用原指标单位，例如利率 4.5 减 4.0 得到 0.5 个百分点。月度变化需要连续的观测期。

规则的 `changes` 用大类 ID 和带符号的百分点表示方向。例如 `{"us_equity": -0.05, "cn_bonds": 0.025, "gold": 0.025}` 允许美国指标偏弱时减持美股，再增配人民币债和黄金。配置中的美元防守组由该组合实际选择的标的构成。内置用美元活期，自定义策略可以指定美债。

1. `allocation_limits.groups` 把股票宽基和主动股仓等资产部分归入同一大类，每个部分归属一处。默认 `max_shift=0.05`，基础比例 20% 的大类可在 15%–25% 之间调整。黄金是独立大类，未分配现金由组合共享。
2. 多条规则对同一大类提出调整时先抵消。先从上期目标减持利空大类，再用已经留存和本次释放的现金加仓。正负幅度参照当期基础或风险平价权重，因此持续相同的信号有同一个目标水平。
3. `max_cash` 默认 25%，约束的是组合目标共享现金。若计划卖出加上原有现金在计划买入后仍会超过上限，按比例少卖。买入预算不足也按比例缩减。无加仓条件时保留已累积的目标现金。实盘与模拟的现金还会受费用、不可成交、应收款和价格漂移影响。
4. 每组只读决策时已公布的本地宏观指标。某个地区核心指标不足时，该地区本期提出零调整，其余地区可独立生效。记录可在 `regimes.json` 核对。旧配置中的 `macro.rules[].weights` 仍能按原有规则使用全部目标权重。

## 波动率调整

通过 `volatility.enabled` 开启。默认用 5 和 30 个交易观察值的均线。美国 VIX 达到 20 且短均线高于长均线进入防守，降至 18 才恢复。跨境预设仅指定 `us_equity`，可显式在该信号的 `groups` 加入 `cn_equity`。防守时约束目标权重，回笼资金计入共享现金。

境内预设只使用华创的上证 50ETF 和沪深 300 隐含波动率。2020 年起，在沪深 300 自身的 30 个有效日线值齐备后切换。两条序列各算各的均线。境内阈值 25 进入、22 退出是示例参数。波指单独开启时恢复按未减仓的目标配置，和宏观一起用时恢复正常后由正向配置条件决定资金是否买回。

## 回测如何记账

1. 初始资金在首个执行日收盘建仓，信号来自此前交易日。后续通常期末形成信号，下一交易日收盘执行。
2. 每天先按旧持仓计算盈亏。到调仓日时，按目标与现有持仓的差额买卖，同一证券跨部分的反向差额优先作内部划转。其余交易日延续持仓，权重随价格漂移。回测截止日保存收盘估值和剩余持仓。
3. 美国ETF价格与USD/CNY分别按已知时间向后对齐，再换算人民币。报价日和可用时点保留在数据文件中；采用已完成报价成交是低频回测的成交近似。
   境内QDII仍设为etf，直接使用其人民币场内价格和中国日历；它的汇率影响已经反映在价格中，不再次换汇。
4. 没有当日可交易报价时保留未完成的买卖差额。后续只重试这些证券原方向的差额，已完成的仓位继续持有。新信号会替换旧目标。缺失价格不倒填未来值。
5. 已持仓但缺报价时，用最后已知价估值。超过 `max_valuation_gap` 后，默认报错；`long_gap_policy=carry_and_flag` 则继续估值并导出明细。默认跨境配置采用后一种方式。
6. 交易成本仅按市场成交净额及已确认的费率计算。现金零收益，允许分数份额。多因子股票的开盘与收盘行情保留分方向的涨跌停限制。整手成交和券商撮合采用回测简化口径。

累计收益与各部分累计盈亏相加核对。年化收益按日历年长度计算，波动及零无风险利率夏普用252个交易日；不足一年时年化值仍是折算值。首次收盘建仓之前的涨跌不计入账户，因此与按上一年最后一天本金计算的年度收益会有差别。

## 与数据模块的数据接口

必需文件为 `prices.csv` 和 `calendar.csv`，直接兼容数据模块输出。财务筛选增加 `stock_features.csv`；动态配置增加 `macro_observations.csv`。这些文件由数据模块产生。

策略 `prepare` 先根据日历和各仓调仓频率列出信号日。多因子选股准备候选池的历史估值、财报、分红、复权日线及可成交方向。全 A 按交易日分区取行情，指数池与自选池按证券获取行情。改变股票池或频率后，以预检结果判断原数据能否复用。

联网运行中断后，可使用 `prepare --cache <原缓存目录>` 复用已完成的原始行情和财务分区。需要更新已归档的历史快照时使用新缓存目录。

## 大类资产风险平价

`allocation.method` 默认为 `fixed`。设为 `risk_parity` 可用当前组合的代理篮子估计风险并配权。与地区宏观和波动率组合时，先计算风险平价，再应用大类区间、信号与共享现金约束。 [风险平价与风险贡献](风险平价与风险贡献.md)
