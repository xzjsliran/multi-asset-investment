# 配置和计算说明

完整可执行示例在 `assets/`。先复制某个示例，再让智能体按用户要求修改。权重用小数：0.12表示12%；ROE、PE及宏观阈值沿用指标原单位，例如ROE门槛8表示8%。

所有资产只做多：`position_policy=long_only`，不允许空头或融资杠杆。大类、动态和证券配权必须有限且非负；大类权重合计不超过100%，剩余留现金。卖出金额可以为负，含义是减少已有持仓。回测与调仓共用`strategykit.decision.decide`。

## 组合分为若干资产部分

每个 `sleeves` 项有独立的 `id`、`weight`、`assets`、`selection`、`weighting` 和 `rebalance`。总权重不得超过1，剩余为零收益现金。

- `allocation_rebalance`：整个组合调整大类预算的频率。
- 每个部分的 `rebalance`：该部分重新选资产、计算内部比例的频率。
- 可选值为 `weekly`、`monthly`、`quarterly`。
- 大类调整但某部分未到选股日时，按该部分现有内部比例缩放资金，不额外选股。
- 只有股票部分到调仓日时，使用股票部分当时的资金，其他部分持仓不变。

`assets` 中写明 `code`、`kind`、`name`。类型为 `etf`、`stock` 或 `us_etf`。可用 `from`（含）和 `until`（不含）规定替代资产的有效区间。例子已有红利ETF、成长ETF的历史切换。

## 四种资产选择方式

| selection.method | 做什么 | 常用参数 |
| --- | --- | --- |
| fixed | 持有用户明确列出的资产 | assets中的有效区间 |
| momentum | 候选池中按历史涨幅排序 | lookback、top_n、min_return |
| quality_value | 行业龙头、质量和估值规则 | min_roe、max_pe_ttm、max_pe、leaders_per_industry、max_per_industry |
| fundamental | 用户自己写的简单基本面条件 | filters、rank_by、top_n、max_per_industry |

自定义规则例子：只筛PE_TTM和年度ROE，然后按PE从低到高取五只：

```json
{
  "method": "fundamental",
  "universe": "all_a",
  "top_n": 5,
  "min_listing_days": 365,
  "exclude_st": true,
  "max_per_industry": 0,
  "filters": [
    {"field": "pe_ttm", "op": ">", "threshold": 0},
    {"field": "pe_ttm", "op": "<", "threshold": 30},
    {"field": "annual_roe", "op": ">", "threshold": 10}
  ],
  "rank_by": [{"field": "pe_ttm", "ascending": true}],
  "fill_shortfall": "cash"
}
```

可用字段：`pe`、`pe_ttm`、`pb`、`dv_ttm`、`total_mv`、`annual_roe`、`annual_ocfps`、`debt_to_assets`、`profit_dedt`、`roe_yearly`。筛选条件之间为“并且”，比较符为 `>`、`>=`、`<`、`<=`、`==`。排序可列多个字段；最后以代码打破并列，保证重跑一致。

`universe` 可填 `all_a` 或明确代码数组。默认上市满一年、排除当时ST；可自行改动。`max_per_industry=0` 表示不限制行业只数。财务字段仍需已公告，估值按历史截面；价格选股不会自动继承原示例的财务门槛。

计划选五只只选出三只时，默认只投资该部分的3/5，缺额留现金。设置 `fill_shortfall=redistribute` 可在入选股票间分完这部分资金。

## 股票如何配权

`weighting.method` 支持 `equal`、`fixed`、`min_variance`。固定配权在各个asset中加 `weight`，程序将其归一到该部分内部100%。

最小方差解的是：

\[
\min_w w^\top\Sigma w,\qquad \sum_iw_i=1,\quad 0\leq w_i\leq u.
\]

Σ取信号日前选中股票的历史收益协方差。默认126个交易日，至少60期所有入选股都有收益的共同样本；不跨缺失价格计算单日收益。

默认用 `0.9 × 样本协方差 + 0.1 × 样本方差对角矩阵`，即 `shrinkage=0.1`。设0就是直接使用样本协方差。`max_weight=0.4` 表示每只最多占该部分40%，不是整个组合40%。

数据不足或求解失败时，本期回退等权并记录原因。入选股票太少、无法在单股上限内分满资金时，各股仍遵守上限，多余资金留现金，例如两只股票、每只上限40%时最多投入该部分80%。

最小方差可能给某只股票0权重；“入选五只”不保证五只都有正持仓。目标是降低估计方差，实际回测未必收益更高或回撤更小。

## 宏观动态配置

`macro.enabled=true` 时按 `macro.rebalance` 检查规则。每条规则有名称、`all`和/或`any`条件、覆盖所有资产部分的完整权重。按顺序采用第一条成立的规则；无规则成立则用基础比例。

条件例子：

```json
{"series": "cn_pmi", "op": ">=", "threshold": 50, "max_age_days": 62}
```

`transform=level` 比较当前水平；`change` 比较最近值与前N期之差；`mean` 比较最近N期均值，N由 `periods` 指定。变化用原指标单位，例如利率4.5减4.0得到0.5个百分点。月度指标有断月时不把隔月差当月度变化。

`macro-cycle.example.json` 用PMI是否达到50和CPI同比是否上升，组成四种状态。它只是可修改的条件规则；状态名称是规则标签。VIX示例描述市场波动，不能直接当成整个经济周期。

数据不足时：`missing=base_weights` 使用基础配置，`missing=hold` 沿用上期大类目标，regimes.json会记录这次缺失。事件先按 `available_at` 过滤，再从每个统计期当时可见的版本中选最新统计期；后来对老月份的修订不会覆盖新月份。

## 回测如何记账

1. 初始资金在首个执行日收盘建仓，信号来自此前交易日。后续通常期末形成信号，下一交易日收盘执行。
2. 每天先按旧持仓计算盈亏，再执行调仓。未到调仓日保持份额，允许权重随价格漂移。
3. 美国ETF价格与USD/CNY分别按已知时间向后对齐，再换算人民币。报价日和可用时点保留在数据文件中；采用已完成报价成交是低频回测的成交近似。
   境内QDII仍设为etf，直接使用其人民币场内价格和中国日历；它的汇率影响已经反映在价格中，不再次换汇。
4. 没有当日可交易报价时保留待成交金额，之后在所属部分资金范围内尝试；新信号会替换旧目标。缺失价格不倒填未来值。
5. 已持仓但缺报价时，用最后已知价估值。超过 `max_valuation_gap` 后，默认报错；`long_gap_policy=carry_and_flag` 则继续估值并导出明细。默认跨境配置采用后一种方式。
6. 成本为零，现金零收益，允许分数份额；当前没有完整的涨跌停、整手、税费或券商撮合。

累计收益与各部分累计盈亏相加核对。年化收益按日历年长度计算，波动及零无风险利率夏普用252个交易日；不足一年时年化值仍是折算值。首次收盘建仓之前的涨跌不计入账户，因此与按上一年最后一天本金计算的年度收益会有差别。

## 与数据模块的数据接口

必需文件为 `prices.csv` 和 `calendar.csv`，直接兼容数据模块输出。财务筛选增加 `stock_features.csv`；动态配置增加 `macro_observations.csv`。这些文件由数据模块产生。

策略 `prepare` 先根据日历产生需要的信号日期，调用数据模块生成财务截面，按配置筛选后再请求入选股票历史行情。无需预先下载全市场所有日线。股票调仓频率改变时会重新生成截面需求。

联网运行中断后，新建工作目录，使用 `prepare --cache <原缓存目录>` 复用成功请求；原始缓存有24小时复用期，超过后重新确认供应商数据。

## 与报告模块的交接

backtest只输出CSV/JSON，具体文件、字段和单位见 [回测结果与报告接口](回测结果与报告接口.md)。结果清单在handoff.json，图表和报告由下一模块读取结果后制作。

## 大类资产风险平价

`allocation.method`默认为`fixed`，保留既有固定比例及宏观规则行为。设为`risk_parity`可按代理篮子的历史协方差均衡大类风险，生成完整示例可用`init --preset risk-parity-demo`。当前与宏观动态配额分别运行；股票内部的最小方差及独立调仓不受影响。新增配置、现金处理、样本不足时的回退及风险贡献口径见[风险平价与风险贡献](风险平价与风险贡献.md)。
