# 大类资产风险平价与风险贡献

## 配权选择

大类配置现在有三种研究路线：固定比例、宏观条件配额、风险平价。股票内部的选股、等权或最小方差，以及独立调仓频率继续使用原有配置。第一版将宏观条件配额与风险平价分别回测，开启两者的配置会提示冲突。

风险平价通过历史协方差，使参与配置的各资产部分承担相等的估计风险。它不估计未来收益。所有目标权重非负，合计不超过100%，未投资部分留现金。

## 配置示例

用`init --preset risk-parity-demo`生成股票宽基、国债、黄金及商品ETF的完整样例。下面展示新增字段：

```json
{
  "allocation": {
    "method": "risk_parity",
    "lookback": 126,
    "min_observations": 60,
    "shrinkage": 0.1,
    "invested_weight": 1.0,
    "fallback": "base_weights",
    "proxies": {
      "equity": [{"code": "510300.SH", "kind": "etf"}],
      "bond": [{"code": "511010.SH", "kind": "etf"}],
      "gold": [{"code": "518880.SH", "kind": "etf"}],
      "commodity": [
        {"code": "159980.SZ", "kind": "etf", "weight": 1},
        {"code": "159981.SZ", "kind": "etf", "weight": 1},
        {"code": "159985.SZ", "kind": "etf", "weight": 1}
      ]
    }
  }
}
```

`proxies`的键必须与实际`sleeves.id`一致。每个篮子内部权重归一化；可以用宽基ETF代表精选股票部分，也可以用实际投资的ETF作为代理。代理只用于估计风险，程序不会因它出现在代理清单里就买入它。计划取数时会自动把代理加入所需行情。

代理应在研究前选定，并确认历史覆盖。代理篮子以固定权重计算每日组合收益，只是风险估计工具，不将它称为实际历史持仓。对精选股票使用宽基代理时，需说明行业、集中度等差异；代理方案变更后另存配置。

`invested_weight`表示分配给这些资产部分的总比例，例如0.95代表保留5%组合现金；省略时使用基础权重合计。原`sleeves.weight`继续作为缺样本时的基础回退比例。`fallback`可为`base_weights`、`hold`或`error`；`hold`沿用上次目标而非假设当前漂移持仓等于上次目标，实际账户须提供该状态。

风险配权只在大类调仓日计算，股票内部调仓日保持大类预算。月末/季末形成信号，下个交易日执行；回测和调仓计划共用同一个决策函数。

## 计算与记录

使用信号日及以前最近`lookback+1`个交易日的研究价格，计算不填补缺失的日收益。只取所有代理共同有效的样本；信号日缺报价、共同样本不足、零波动或求解失败时，按配置回退并记下原因。

协方差为`(1-shrinkage) × 样本协方差 + shrinkage × 对角协方差`。默认收缩0.1，用于降低相关性估计不稳定的影响。求解正权重的凸风险预算问题后归一化，再乘投资比例；检查风险份额与等份预算的误差不超过1e-5。

`regimes.json`保存代理、样本日期、有效样本数、收缩系数、协方差、目标权重、估计年化波动与风险贡献。未得到有效估计时不填造风险占比。与固定基础比例的对照保留相同数据、内部规则和调仓日历，导出为`static`场景。

## 风险贡献的两种口径

**目标配置风险估计**：对信号日前的代理协方差Σ和目标权重w，资产i的方差贡献为`w_i(Σw)_i`，风险占比为该值除以`wᵀΣw`。这反映模型的目标；未包含整手交易、未成交、实际股票与代理的差异。

**实际回测波动贡献**：报告模块先计算每部分的日收益贡献`c_i,t = 当日该部分盈亏 / 上一日组合权益`，核对各部分之和等于组合日收益r。年化波动贡献为`Cov(c_i,r)/std(r) × sqrt(252)`，合计等于报告中的年化波动率；占比合计为100%。共同起始日记0，保持与绩效指标一致。

风险贡献可以为负，也可能有部分超过100%，反映协方差的分散作用；不代表存在空头。零波动组合的风险占比不定义。收益贡献、风险贡献和配置权重是不同指标。

多策略对照按共同区间重算风险贡献。相关性展示的是各资产部分对组合的日收益贡献序列，包含仓位变化影响。只有净值、缺少分部分盈亏时保留绩效分析，不推测风险来源。

## 开发复现

在WorkBuddy中可要求：先解释最小方差和风险平价的区别，再写独立协方差配权函数；用对角协方差验证风险平价等于逆波动率权重；随后接入共同决策函数，验证更改未来行情不会改变既有决策，并检查调仓计划与历史回测同日目标一致。最后让报告从每日盈亏独立复算风险贡献，验证加总、负贡献及共同区间截取。

参考：[Balanced Portfolio优化器](https://github.com/hxlog/balanced-portfolio/blob/main/bp_api/quant/optimizer.py)。本实现使用SciPy求解独立的风险预算问题，并沿用本项目既有日历、数据边界及现金处理。
