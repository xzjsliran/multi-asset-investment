# 组合管理与调仓计划

接收选定策略、已确认的账户快照和数据截止时间，输出下一次调仓的目标配置、买卖清单及资金约束。所有资产只做多，卖出仅减少已有持仓。生成计划后，账户记录保持原状。

本模块与历史回测共用决策逻辑：大类配置、宏观规则、风险平价、选股及最小方差配权均由策略kit计算。调仓kit处理实际份额、原始参考价、交易单位、各币种现金和买卖净额。报告由报告kit呈现。

风险平价计划保留代理、估计窗口、样本数和目标风险贡献。使用缺数时沿用上期目标的选项，实际账户须提供上次目标配置。目标风险估计与交易单位、可卖数量和现金约束后的计划分别记录。

实际使用先向用户确认策略和持仓，确认记录与输入内容关联；策略、持仓或时间请求变化后重新确认。演示可以使用原有策略生成历史模拟账户。
